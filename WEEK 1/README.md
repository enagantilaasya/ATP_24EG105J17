# JavaScript Array & Function Programs

This Week Contains The Topic  

## Arrays  
Arrays are used to store multiple values in a single variable. They help in organizing and managing collections of data efficiently.
## Functions  
Functions are reusable blocks of code designed to perform a specific task. They improve code readability and reduce repetition.
## Loops  
Loops are used to execute a block of code repeatedly until a condition is satisfied. Common loops in JavaScript include `for`, `while`, and `for...of`.

## Conditional Statements  
Conditional statements are used to make decisions in a program based on certain conditions. Examples include `if`, `else if`, and `else`.

## Rest Parameters  
Rest parameters allow a function to accept multiple arguments as an array using the `...` syntax. They are useful when the number of inputs is unknown.

## Array Operations (splice)  
The `splice()` method is used to add, remove, or replace elements in an array at specific positions.

## Searching and Summation Logic  
Searching logic is used to find specific elements in an array, while summation logic is used to calculate the total of numeric values.
