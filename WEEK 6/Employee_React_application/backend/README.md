# BackEnd OverView
## Technologies Use
- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
## Backend Project Structure
backend\
│\
├── APIs\
│   └── empApp.js\
│\
├── models\
│   └── EmpModel.js\
│\
├── node_modules\
│\
├── package.json\
├── package-lock.json\
└── server.js\
## Installation Steps
### Step 1: Install Dependencies
```bash
npm install express mongoose mongodb cors
```
### Step 2: Start the Backend Server
```bash
node server.js
```
